# Airline Dashboard (Power BI)

# ✈️ Airline Dashboard - Power BI Project

## 📌 Project Overview

This Power BI dashboard provides an interactive analysis of airline operations, passenger traffic, flight performance, delays, airports, aircraft utilization, and cancellations. The report enables users to monitor KPIs, identify trends, and make data-driven decisions using dynamic filters and visualizations.

---

# 📊 Dashboard Pages

## 🏠 1. Main Dashboard

### Purpose

Provides a high-level overview of airline performance.

### Key KPIs

* Total Flights
* Total Revenue
* Total Passengers
* Average Delay
* Cancellation Rate
* On-Time Performance

### Visuals

* KPI Cards
* Monthly Flight Trend
* Revenue Trend
* Flight Status Distribution
* Interactive Slicers

### Business Insight

Allows management to quickly understand the overall health and performance of airline operations.
